# 🎓 Student Grade Tracker

A console-based Java application developed as part of my Java Programming Internship.

## 📖 Overview

The Student Grade Tracker allows users to add students, record multiple grades, and generate reports showing each student's academic performance.

## ✨ Features

- Add student records
- Store multiple grades for each student
- Calculate average grade
- Display highest grade
- Display lowest grade
- Generate student reports
- Menu-driven console application
